# v1.0-console — Console implementation

## Release scope

The initial console implementation of a two-AZ Linux web service with private compute, health-driven instance replacement, operational logs, and audit evidence.

### Included

- Custom VPC, two public subnets, two private subnets, internet gateway, private route tables, and one shared public NAT gateway.
- Internet-facing ALB, application target group, launch template, and fixed two-instance Auto Scaling group with ELB health checks.
- Nginx homepage and `/health` endpoint provisioned by user data.
- EC2 role and Session Manager access without inbound SSH.
- Centralized access/bootstrap evidence, configured error-log collection, health alarm, and an actually received SNS alarm notification.
- CloudTrail S3 management-event delivery with a matched successful tag change.
- AWS Config resource-level results for restricted SSH and attached-volume encryption.
- Architecture diagram, console deployment guide, operations runbook, design decisions, security evidence, and the recovery incident report.
- Normalized request observations, reproducible analysis, local validation, and a repository validation workflow.

## Recovery evidence

**265 requests; 259 HTTP 200; six HTTP 502; 97.74% sampled success.** The intermittent error window spanned 19.921 seconds between failing request starts. All 204 subsequent samples succeeded. Automatic replacement restored two healthy targets, and the alarm returned to OK.

The original failure is retained in the evidence rather than edited out of the outcome. Exact MTTR is unavailable because the fault marker was not captured.

## Open verification and design limitations

- Project-specific spend and budget alert configuration/delivery are pending verification.
- The final saved ResourceCompliance recording selection and Config retention setting were not independently captured.
- The single NAT gateway creates an AZ dependency for egress; the application uses HTTP without TLS.
- No demand-based scaling, load-capacity test, full-AZ exercise, or production SLA is claimed.
- The reusable public PowerShell probe is an adapted tool, not the exact script execution that produced the retained dataset.

## Next implementation

Rebuild the understood infrastructure with Terraform, preserving the operational behavior and evidence standard. Terraform provisioning, remote state, drift handling, and automated infrastructure delivery are not part of this console release.
